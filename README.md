# MP4 Video Format Basics

MP4 (MPEG-4 Part 14) is the everyday video format for phones, browsers and TVs. If you simply want to turn a clip into a playable file, a [youtube to mp4](https://yt2mp4.live/) tool is the quickest route. The notes below explain what is inside an MP4 file.

## What is inside an MP4 file?

An MP4 is a container. It bundles video, audio and optional subtitles into one file. The most common video codec inside it is H.264, usually paired with AAC audio.

## Common resolutions

**360p and 480p** are small files that suit slow connections.

**720p** is a good balance of sharpness and size for phones.

**1080p** is the standard choice for laptops and TVs.

## Compatibility

H.264 MP4 files play on almost every modern device without extra software, which is why MP4 remains the safest default for sharing and offline viewing.
